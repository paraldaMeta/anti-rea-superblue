# Install anti-rea-protect (Cursor Skill)

This skill is **bundled in** [bla-hardened](https://github.com/paraldaMeta/bla-hardened) under
`.cursor/skills/anti-rea-protect/`. It tells the agent how to run SuperBlue + server-lock
on **your** repo.

## Option A — One command (recommended)

From **your app project root** (not inside bla-hardened):

```bash
curl -fsSL https://raw.githubusercontent.com/paraldaMeta/bla-hardened/main/scripts/install-cursor-skill.sh | bash
```

This copies the skill into `.cursor/skills/anti-rea-protect/` and clones the toolchain to
`.bla-hardened/` if missing.

## Option B — Copy skill only

```bash
mkdir -p .cursor/skills
git clone --depth 1 https://github.com/paraldaMeta/bla-hardened.git /tmp/bla-hardened
cp -R /tmp/bla-hardened/.cursor/skills/anti-rea-protect .cursor/skills/
rm -rf /tmp/bla-hardened
```

First time you use the skill, the agent will clone `.bla-hardened/` (see SKILL.md step 0).

## Option C — Submodule (team pin version)

```bash
git submodule add https://github.com/paraldaMeta/bla-hardened.git .bla-hardened
mkdir -p .cursor/skills
cp -R .bla-hardened/.cursor/skills/anti-rea-protect .cursor/skills/
```

## Use in Cursor

1. Open your project in Cursor.
2. In chat: **`@anti-rea-protect`** or say e.g. "用 anti-rea-protect，路线 R1 生产，扫 `src/`".
3. Answer route + target when asked; let the agent run commands.

Project skills in `.cursor/skills/` apply to that workspace. Re-run the install script
after upgrading bla-hardened to refresh the skill files.

## What gets installed where

| Path | Purpose |
|------|---------|
| `.cursor/skills/anti-rea-protect/` | Agent instructions (this skill) |
| `.bla-hardened/` | SuperBlue + server-lock CLI (cloned on demand) |
| `.superblue-out/` | Generated by R1/R2 (gitignore recommended) |
| `server-lock/` | Copied into **your** project during R3/R4 |
